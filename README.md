# FinanSys Core

Sistema full-stack para gestão financeira (contas a pagar/receber, fluxo de caixa, DRE) com autenticação JWT e dashboard responsivo.
---
Tecnologias

Back-end
- Node.js + Express
- PostgreSQL
- JWT
- Bcrypt

Front-end
- HTML5, CSS3, JavaScript
- Fetch API

DevOps
- Git & GitHub

Funcionalidades

- Autenticação JWT
- CRUD de contas a pagar e receber
- Fluxo de caixa e DRE
- Filtros e pesquisa
- Paginação

---

Como executar


git clone https://github.com/italofrnd/finansys-core.git
cd finansys-core
npm install
cp .env.example .env
npm run dev
